# Simple Interest Calculator

A simple interest calculator that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- Principal amount
- Rate of interest
- Time period

## Output

The calculator displays the calculated simple interest.

## Usage

Enter the principal amount, rate of interest, and time period. The calculator calculates and displays the simple interest.
